# Карьерная траектория ИТМО

Новый проект Центра карьеры ИТМО: короткая rule-based анкета, которая формирует карьерный фокус, ближайшие действия, ориентиры, темп и рекомендации.

Текущий статус: завершена только **PHASE 0**. Реализован чистый технический scaffold и проектная документация; бизнес-функции ещё не разрабатывались.

## Локальный запуск

Требуется актуальная LTS-версия Node.js и npm.

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Технологическая основа

- Next.js 16 с App Router;
- React 19;
- TypeScript в strict-режиме;
- Tailwind CSS 4;
- ESLint.

PostgreSQL/Supabase, Zod, аутентификация, импорт Excel, rule engine, PDF и admin panel будут подключаться только в соответствующих следующих фазах.
