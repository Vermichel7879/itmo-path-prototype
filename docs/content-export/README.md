# Экспорт контента текущего frontend

Эта папка содержит фактические вопросы и варианты ответов текущего прототипа по каждой из трёх программ.

Источники контента:

- `src/data/programs/*.json` — программы, карьеры, навыки, дисциплины, выборные группы, события, действия и ресурсы ЦКО;
- `src/data/prototypeChoices.ts` — общие продуктовые вопросы первого, третьего и четвёртого курса и mapping ресурсов ЦКО;
- `src/game/electiveResolver.ts` — вычисление реально показываемого elective-блока;
- `src/App.tsx` — порядок экранов и подписи вопросов.

Для каждой программы созданы две эквивалентные версии:

- `*.questions-and-answers.json` — машиночитаемый экспорт;
- `*.questions-and-answers.md` — удобная текстовая версия.

JSON включает служебные ID, потому что они нужны для проверки связей. Frontend не показывает эти ID пользователю.

Повторная генерация после изменения исходных данных:

```powershell
npm.cmd run export:content
```

Важно: генератор повторяет текущую формулу выбора meaningful elective. Он предназначен для аудита текущего поведения, а не является вторым runtime-источником данных.
